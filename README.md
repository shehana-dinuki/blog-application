# Blog Application

A responsive Blog Application developed using **PHP, MySQL, HTML, CSS, and JavaScript**.

Users can register and log in, create and manage blog posts, search for blogs, browse categories, and view individual blog posts.

## Features

* User Registration & Login
* User Authentication & Authorization
* Create, Edit & Delete Blog Posts
* View All Blogs
* Single Blog View
* Search Blogs
* Blog Categories
* Responsive Design

## Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** PHP
* **Database:** MySQL
* **Local Development:** XAMPP
* **Hosting:** InfinityFree
* **Version Control:** Git & GitHub

## Database

The application uses **MySQL** to store user and blog information.

Main tables:

* `user`
* `blogpost`

## Local Setup

1. Install **XAMPP**.
2. Start **Apache** and **MySQL**.
3. Place the project inside the `htdocs` folder.
4. Create the `blog_app` database using phpMyAdmin.
5. Import the provided SQL file.
6. Configure the database connection.
7. Open the application in your browser:

```text
http://localhost/blog-application/
```
